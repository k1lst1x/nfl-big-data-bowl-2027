# Notebooks

`00_data_inventory.ipynb` inventories the nine files and reports preliminary WR
coverage. `01_data_inventory.ipynb` is the reproducible Colab-compatible
deliverable: it inventories the official files, validates player joins, and
exports the 2023-2025 WR cohort. Later notebooks will cover YAC outcome
construction, Combine tracking features, and model comparisons.

Each committed notebook should run from top to bottom using the documented local
data location, without manual edits between cells.
